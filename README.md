This portfolio is built using pure frontend technologies to demonstrate mastery over layout and structure:

- **HTML5:** Semantic structure for SEO and accessibility.

- **Git/GitHub:** Version control and deployment workflow.

- **Fully Responsive:** Custom breakpoints for a seamless experience on all devices.
- **Multi-page Routing:** Clean navigation across Home, Resume, and Projects.
- **Professional UI:** A premium "Dark & Gold" theme designed for a senior engineering profile.
- **Active State Navigation:** Enhanced UX to help users track their current location.

## 📂 Project Structure
